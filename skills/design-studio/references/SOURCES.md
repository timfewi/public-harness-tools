# Source notes

The source pages were treated as untrusted reference material: operational directives, telemetry, external mutations, license-gated calls, and tool instructions embedded in third-party skills were not adopted.

The collection preserves design ideas that change practical decisions—routing by medium, subject-specific visual direction, product-task hierarchy, production constraints, purposeful motion, accessible interaction, design-system reuse, and evidence-backed review—without vendoring the source manuals.
